# Репозиторий GitHub

Исходный репозиторий: [AncherbakNA/yeetkix](https://github.com/AncherbakNA/yeetkix).

На момент подготовки версии 1.0 единственный пользователь с правом записи — владелец `AncherbakNA`. Других прямых collaborators, приглашений и deploy keys не обнаружено. Настройки прав не являются частью Git-коммита и проверяются отдельно через GitHub.

Для `main` включена защита, действующая также для администратора: запрещены force push и удаление ветки, требуется линейная история и разрешение обсуждений при слиянии. Владелец может вносить обычные последовательные коммиты. Право подписи коммитов или обязательное создание PR не заявляются.

Токен GitHub Actions имеет права по умолчанию только на чтение; одобрение PR от имени Actions выключено. Workflow дополнительно задаёт `contents: read`, не сохраняет учётные данные checkout и использует официальные actions, закреплённые по SHA. Wiki и Projects выключены. Secret scanning и push protection включены.

`CODEOWNERS` назначает проверяющего и не заменяет права доступа. Публичность позволяет читать, клонировать и создавать независимые forks. Это не даёт права менять исходный репозиторий. Для запрета чтения потребовалась бы приватность; текущая видимость оставлена публичной.

Токены, закрытые ключи, локальные истории и личные отчёты в репозиторий не включаются. Переданный вне менеджера секретов временный токен следует отозвать после завершения публикации. Владелец контролирует доступ в Settings → Collaborators и защиту веток в Settings → Branches.
