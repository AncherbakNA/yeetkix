# YEETKIX 1.0

Утилита для **macOS 14+ на Apple Silicon (ARM64)**: поиск кэшей, дубликатов, остатков приложений и файлов, занимающих место. Найденное переносится в Корзину только после выбора и подтверждения.

**Разработано с помощью ИИ — OpenAI Codex.** ИИ использовался при создании кода, интерфейса, тестов и документации. Требования и ограничения задавал автор проекта. [Подробности](docs/AI_DISCLOSURE.md).

## Установка из исходников

Нужны Mac с чипом Apple M-серии, macOS 14+, Command Line Tools со Swift 5.9 или новее и интернет для первой загрузки Sparkle. Command Line Tools устанавливаются командой `xcode-select --install`. Сборки для Intel нет.

```sh
git clone https://github.com/AncherbakNA/yeetkix.git
cd yeetkix
bash scripts/build-app.sh
open build/Yeetkix.app
```

Собранное приложение можно скопировать в «Программы». Для создания ZIP, DMG и SHA-256:

```sh
bash scripts/package-release.sh
```

В `build/` появятся `Yeetkix.app` и файлы `Yeetkix-1.0-macOS-arm64.zip`, `.dmg`, `.sha256`. Предыдущее приложение сохраняется в `build/Previous/`. Готовые сборки CI доступны в разделе Actions соответствующего запуска. Это локальная ad hoc сборка: Developer ID, нотариализация и канал автоматических обновлений пока не настроены.

## Возможности

- Кэши и журналы, включая известные sandbox-контейнеры и подписанные общие группы.
- Кэши npm, pnpm, pip, Yarn, Homebrew и архивы Cargo.
- Дубликаты с проверкой содержимого и сохранением одной копии.
- Остатки удалённых приложений, большие файлы и просмотр Загрузок.
- Сгенерированные сборки, индексы и кэши Xcode.
- Просмотр приложения и связанных данных перед удалением, включая целые VM UTM. Конкретный файл или папку в другом месте можно добавить вручную.
- Карта папок и старые завершённые локальные резервные копии iPhone/iPad.
- Отдельные действия для неиспользуемых ресурсов Docker и недоступных симуляторов Xcode.
- Исключения, история операций и восстановление из Корзины.
- Отчёт по всем запланированным папкам, поиск по статусу, экспорт JSON и встроенное руководство.

## Использование

1. Выберите раздел и запустите проверку. Само сканирование ничего не удаляет.
2. Просмотрите пути и статусы в списке и отчёте. Нужное можно открыть в Finder или добавить в исключения.
3. Отметьте ненужные объекты и подтвердите перенос в Корзину.
4. Для отмены откройте «История очистки» → «Восстановить».

Возраст файла не доказывает его ненужность. Документы, VM и резервные копии выбираются вручную. Перенос в Корзину не освобождает место до её очистки пользователем в Finder. Docker и simctl выполняют необратимые действия с отдельным подтверждением; восстановление из Корзины к ним не применяется.

Для UTM: «Приложения» → UTM → дождитесь проверки мест хранения. Для нестандартного расположения есть выбор папки с `.utm` и кнопка «Добавить файл или папку…». VM показаны целиком и по умолчанию не отмечены.

## Доступ и ограничения

Приложение работает с правами текущего пользователя. Отсутствующая, недоступная, защищённая и непроверенная папки имеют разные статусы. В настройках можно подключить точную папку; отдельные разрешения управляются в настройках конфиденциальности macOS. После их изменения перезапустите приложение.

Нельзя гарантировать обнаружение каждого файла любой программы: документы могут лежать произвольно, диски — быть отключены, а macOS — закрывать доступ. Неизвестные общие данные защищаются. Кэш uv требует штатной команды uv и не разбирается по отдельным файлам.

История, исключения и bookmarks хранятся локально. Отчёт JSON содержит пути к файлам и сохраняется только по вашему выбору. Перед его публикацией проверьте личные сведения.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `Sources/Luma/` | SwiftUI-интерфейс, разделы, настройки и состояние приложения |
| `Sources/LumaCore/` | Поиск, защита файлов, дочерние процессы, Корзина и восстановление |
| `Tests/LumaCoreTests/` | Исполняемые проверки на искусственных данных |
| `Resources/` | Иконка приложения |
| `scripts/` | Сборка, упаковка и подготовка будущего выпуска |
| `docs/` | Руководства, правила работы и отчёты проверок |
| `.github/` | CI и сведения о внесении изменений |
| `Package.swift`, `Package.resolved` | SwiftPM и закреплённый Sparkle 2.10.1 |

Имена `Luma` и bundle ID `local.luma.cleaner` сохранены от ранней версии для совместимости настроек и истории. Название утилиты — YEETKIX.

## Проверки и документация

```sh
swift run -c release -debug-info-format none LumaChecks
```

Тесты создают собственные временные файлы, макеты приложений и VM. Настоящие пользовательские документы и ресурсы Docker/simctl они не удаляют. CI запускает проверки и сборку на ARM64 с правами токена только на чтение репозитория.
