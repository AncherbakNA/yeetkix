# YEETKIX 0.3: проверка

26 октября 2026 года, macOS 26.6, Apple Silicon.

- `swift run LumaChecks`: 28/28. Сохранены все прежние проверки истории, ошибок, границ путей и восстановления.
- Добавлены проверки дубликатов с разными именами, одинаковыми префиксами и разным содержимым; жёстких ссылок; сохранения одной копии; изменения сохраняемой копии; поддельного хеша; отмены; сравнения через отдельный процесс и между папками.
- Для остатков проверены установленные приложения и их помощники, повторная установка перед очисткой, неполный каталог, перемещение и восстановление, защита общих данных разработчика при установленном продукте.
- Для Xcode проверены Build внутри DerivedData, сгенерированные app-пакеты, индексы, общие кэши, символы устройств; защита исходников и архивов; активный процесс сборки; возврат файла на место.
- На реальном Mac каталог `/Applications`, `~/Applications`, `/System/Applications` успешно проверен; найдено 88 идентификаторов. Системные демоны из CoreServices не используются как каталог пользовательских приложений.
- Три новых раздела проверены в UI исключительно на созданных тестовых данных: паре одинаковых файлов в отдельном каталоге Movies, файле фиктивного отсутствующего приложения в Application Support и искусственном артефакте Build Xcode.
- В дубликатах проверены смена сохраняемой копии, запрет выбора сохраняемой копии и действие «Выбрать копии». Перемещён только `copy-me.txt`; `keep-me.txt` остался с исходным содержимым.
- Во всех трёх разделах подтверждение показывало единственный созданный тестовый файл. После переноса все три файла возвращены через раздел История. Содержимое всех четырёх тестовых файлов сверено побайтно с исходным.
- В новом списке остатков поиск `com.microsoft` не вернул кандидатов при установленных приложениях Microsoft. Эти пользовательские данные не выбирались и не перемещались.
- По завершении удалены только четыре созданных файла после сверки содержимого. Созданные для теста каталоги удалялись только если оставались пустыми. История проверок сохранена.
- Доступ к закрытым папкам macOS не расширялся. В проверке дубликатов закрытые папки пропущены штатной кнопкой; доступная папка со своими тестовыми файлами проверена полностью.

Название YEETKIX / «Йиткикс» проверено точными открытыми поисковыми запросами, включая запросы по App Store, GitHub и Google Play. Совпадений не найдено. Это не подтверждение абсолютной всемирной уникальности имени.
