# Проверка YEETKIX 0.4

26 октября 2026, Mac Apple Silicon, macOS 26.6.2, Swift 6.3.3 / Command Line Tools. Только ARM64; Intel исключён по просьбе пользователя.

## Автоматические проверки

- `swift run -debug-info-format none LumaChecks`: 37/37.
- `swift run -c release -debug-info-format none LumaChecks`: 37/37.
- Дополнены проверки целых приложений, связанных данных, активного приложения после обхода дерева, изменения содержимого в Корзине, человеческих имён и неоднозначных владельцев.
- Целая синтетическая резервная копия: просмотр, согласованный с картой размер, перенос, восстановление исходных байтов. Проверены предел карты и стабильность манифеста при перемещении и вариантах `/var` / `/private/var`.
- Команды Docker/simctl заменены подставным исполнителем. Проверены точный UUID, выключенное недоступное устройство, отказ при запущенном симуляторе, локальные sockets, смена daemon ID, образы без force и с `--no-prune`, кэш с `until=168h`, отказ для запустившегося контейнера и отсутствие удаления томов.
- Журнал управляемых ресурсов: намерение и результат дают одну запись; повреждение журнала останавливает команды.
- Sparkle подписал одноразовые искусственные данные ключом из временного файла. CryptoKit принял подпись исходных данных и отверг изменённые. Keychain не менялся; временный seed удалён вместе с собственной тестовой папкой.
- Конфигурация сборки: по умолчанию нет SUFeedURL и автоматических проверок, HTTP отклонён, корректные HTTPS и публичный ключ приняты. Тестовые адреса в сеть не отправлялись.

## Проверка нативного интерфейса

Создан уникальный неисполняемый тестовый `.app` в `~/Applications` и отдельная папка его данных в `~/Library/Application Support/test.yeetkix.qa.<случайный-токен>`. В интерфейсе найден только этот пакет; связанные данные сначала не отмечены. После ручного выбора подтверждение показало ровно два собственных пути, 628 байт.

Оба объекта перенесены в настоящую Корзину через FileManager, затем восстановлены по двум записям истории. SHA-256 всех собственных файлов после восстановления совпал с исходным. Тестовые файлы удалены только после сверки; удаление выполнялось по точному списку созданных файлов, папки — только пустые. В истории сохранены две записи со статусом «Восстановлен».

Для карты создана папка с тремя файлами: 64 000, 16 000 и 4 000 байт. Системный выбор папки, карта 84 КБ, вход в подпапку 64 КБ и возврат к 84 КБ проверены. Все три файла сверены и убраны по тому же списку. Права на личные папки не расширялись.

Попытка создать отдельную синтетическую копию внутри настоящего MobileSync остановлена macOS с EPERM ещё до создания каталогов. Разрешения не менялись. Поэтому перенос настоящего MobileSync через UI не проверялся; полный цикл резервной копии покрыт временной тестовой домашней папкой. Нативный поиск в текущей среде завершился без подходящих копий.

Полный Xcode/simctl отсутствует, Docker daemon выключен. Интерфейс показал соответствующие сообщения и ничего не запустил. Настоящие симуляторы, контейнеры, образы и кэш Docker не удалялись.

В Настройках финальной сборки показаны версия 0.4, локальная сборка и неподключённый канал обновлений.

## Артефакты

- `build/Yeetkix.app`: главный исполняемый файл `arm64`, локальная ad hoc подпись.
- `build/Yeetkix-0.4-macOS-arm64.zip`: проверена целостность ZIP.
- `build/Yeetkix-0.4-macOS-arm64.dmg`: `hdiutil verify` подтвердил контрольные суммы.
- `build/Yeetkix-0.4-macOS-arm64.sha256`: обе SHA-256 проверены.
- `codesign --verify --deep --strict` проходит с вложенным Sparkle.

Developer ID, нотариализация, публикация и рабочий сервер обновлений отложены пользователем. Полный цикл установки сетевого обновления сейчас не заявляется. Обход ограничений macOS и очистка Корзины не выполнялись. Пользовательские файлы не перемещались и не удалялись.
