# Проверка YEETKIX 1.0

26 октября 2026. Build 8, Apple Silicon, macOS 14+. Локальная сборка ad hoc; Developer ID, нотариализация и канал сетевых обновлений не настроены.

## Изменения для 1.0

Убраны рекламные слоганы и сленг. Обзор и разделы описывают выполняемые действия. «Умная очистка» переименована в «Кэши и журналы». Настройки доступа сворачиваются в список с поиском. Добавлены встроенная справка, команды меню, прокручиваемый отчёт по папкам и сохранение JSON. Пометка об использовании ИИ есть в приложении, README и отдельном документе.

Отчёт перечисляет все запланированные места, включая не проверенные после остановки или лимита. Ошибки чтения помечают результат как частичный; недоступный родитель каталога приложений не означает отсутствие установленных программ. Повторяющиеся кандидаты нормализуются при поступлении частичных результатов. Для неотвечающих Caches/Logs sandbox-контейнеров установлен тайм-аут 5 секунд без прогресса; остальные обычные места используют 20 секунд.

При финальной нативной проверке найдена ошибка: `skipDescendants()` вызывался и для файлов/ссылок. Foundation применяет эту команду к последнему каталогу, из-за чего могли скрываться соседние ветки. Теперь она вызывается только для настоящего каталога. Исправлены обычный сканер, манифесты папок, карта диска, каталоги приложений, остатки и поиск VM. Ссылки не обходятся.

Контрольные суммы пакетов используют переносимые имена файлов. Руководство и пометка об ИИ включаются в ресурсы приложения. Предыдущие приложения сохраняются в build/Previous.

## Автоматическая проверка

Финальная release suite: **60/60**, без предупреждений компилятора. Команда:

```sh
swift run -c release -debug-info-format none LumaChecks
```

Сохранены все проверки безопасности 0.6: точные категории и корни, возраст, запущенные владельцы, замены файлов, ссылки, исключения, дубликаты, повторная установка приложения, UTM, общие контейнеры, журналы и восстановление. Новые проверки:

- Остановка процесса и общий лимит отражаются статусом каждого запланированного места. Завершённые результаты сохраняются.
- Недоступный родитель каталога приложений и Library не трактуется как отсутствие данных.
- Экспорт JSON сохраняет статусы и метаданные без содержимого файлов, bookmarks и внутренних повторных кандидатов.
- Перекрывающиеся корни не удваивают результат; ошибочный частичный проход не объявляется полным.
- 12 деревьев с файлами, блокировками и ссылками: найдены все разрешённые соседние файлы; манифест включает все 48 объектов, исключение после ссылок блокирует перенос предка, карта сохраняет все 12 веток и 24 настоящих файла.
- В выбранной папке найдены все 8 искусственных VM среди перемежающихся ссылок; цели ссылок не изменены.

Все изменяемые данные этих проверок создаются в уникальных временных Fixture-каталогах. Реальные ресурсы Docker/simctl подменены тестовыми командами. Пользовательские документы и VM не удаляются.

## Нативная проверка

Обзор 1.0 открыт и проверен: нейтральные тексты, разделы утилиты и кнопка руководства. Встроенное руководство открывается без сети, подробный GUIDE.md включён в bundle. Настройки показывают версию 1.0, пометку об ИИ и свёрнутый список 117 мест доступа. Разрешения macOS не расширялись.

Открыт новый отчёт: видны 8 мест раздела кэшей разработки, отдельные статусы отсутствующих папок, работающих инструментов и доступного Homebrew. Экспорт через NSSavePanel создал собственный тестовый JSON в build/ с восемью местами и без bookmarks. Этот локальный файл не включается в Git.

Для проверки обхода создан единственный собственный старый файл в уникальной папке кэша Homebrew. До исправления пропуска ссылок он не попадал в кандидаты; после исправления независимая read-only проверка нашла его и 2317 кандидатов в доступной части кэша. Это не запуск очистки пользовательских файлов.

В окончательной сборке нативный поиск также показал 2317 кандидатов. Список отфильтрован по уникальному имени собственного файла; в подтверждении проверены ровно один объект и 62 байта. Только этот файл перенесён через системную Корзину и восстановлен через UI истории. Содержимое сверено побайтно. Затем удалены только собственный файл и его пустая уникальная папка. Настоящие пользовательские файлы не переносились и не удалялись.

Локальная подпись проверяется `codesign --verify --deep --strict`; Info.plist — `plutil -lint`; основной исполняемый файл — `lipo -archs` (arm64). ZIP, DMG и переносимые SHA-256 проверяются отдельно. Обычная сборка включает руководство и не содержит токена публикации.

Подготовлены README, GUIDE, AI_DISCLOSURE, CODEOWNERS и CI на ARM64. Workflow закрепляет официальные actions по SHA, использует `contents: read` и не сохраняет учётные данные checkout. Настройки доступа проверены отдельно: только владелец, без других collaborators, приглашений и deploy keys; main защищена от force push и удаления, secret scanning и push protection включены. Подробности — в [REPOSITORY.md](REPOSITORY.md).

История, локальные отчёты и каталоги сборки исключены из публикации. Токен не сохраняется в исходниках, Git URL, Git config или файлах помощника авторизации.

## Ограничения

Произвольные документы, отсутствующие диски и закрытые macOS области не позволяют гарантировать нахождение каждого файла любого приложения. Недоступные и непроверенные места отражаются явно. Неизвестные общие данные защищены; кэш uv очищается его штатными командами. Перенос в Корзину освобождает место только после её очистки пользователем. Docker/simctl не восстанавливаются через Корзину. Нотариализация и публичный подписанный выпуск здесь не заявляются.

Основание исправления обхода: [документация DirectoryEnumerator Apple](https://developer.apple.com/documentation/foundation/filemanager/directoryenumerator) — перечисление не обходит символические ссылки, `skipDescendants` применяется к последнему полученному подкаталогу.
