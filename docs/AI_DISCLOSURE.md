# Использование ИИ

**YEETKIX разработан с помощью ИИ — OpenAI Codex.** ИИ использовался при разработке Swift/SwiftUI-кода, интерфейса, тестов, сценариев сборки и документации. Назначение утилиты, требования и ограничения задавал автор проекта.

Проверки изменения файлов выполняются на специально созданных временных данных, искусственных VM и макетах приложений. Внешние команды Docker/simctl в тестах подменяются. Результаты локальной проверки описаны в отчётах VALIDATION в этой папке.

Участие ИИ не гарантирует отсутствие ошибок. Возраст или расположение файла не доказывают его ненужность; выбор и подтверждение операции остаются за пользователем. Упоминание OpenAI описывает способ разработки и не означает независимого аудита или сертификации приложения.
