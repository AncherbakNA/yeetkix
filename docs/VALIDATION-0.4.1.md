# YEETKIX 0.4.1 — отсутствующие папки

26 октября 2026. ARM64, macOS 26.6.2.

Причина ложного «Нет полного доступа»: защитная проверка сравнивала целые URL. ScanRoot помечает URL как каталог; для отсутствующего каталога Foundation не выводит такую же отметку у проверочного URL. Пути совпадали, но URL считались разными, и проверка возвращала denied до проверки существования.

В обычном сканере и сканере остатков теперь сравниваются нормализованные пути. Разрешённый список и остальные защитные проверки сохранены. Отсутствие каталогов не требует расширения разрешений macOS.

- Release-проверки: 38/38, без предупреждений компилятора.
- Новая проверка: отсутствующие корни Xcode, очистки, Загрузок, больших файлов, Корзины, дубликатов и остатков получают missing, без записей inaccessible.
- Проверена сериализация WorkerRequest с отметками каталогов в URL.
- Настоящий дочерний процесс `.app` вернул missing для всех трёх отсутствующих каталогов Xcode, без inaccessible и без найденных файлов.
- Нативный интерфейс: выполнено отдельное сканирование Xcode; в Настройках у всех трёх строк виден статус «Папки нет» и версия 0.4.1.
- Подпись, SHA-256 обоих архивов и целостность DMG проверены.
- Версия сборки 0.4.1, build 5. ZIP/DMG только ARM64, подпись ad hoc.

Пользовательские файлы не перемещались, разрешения macOS не менялись.
