# YEETKIX 0.5 — связанные данные и виртуальные машины

26 октября 2026. macOS 26.6.2, Apple Silicon. Версия 0.5, build 6. Только локальная ARM64-сборка.

## Причина и изменение

В 0.4 удаление приложений проверяло только обычные каталоги Library по точному bundle ID и части имён. Контейнеры sandbox, Group Containers и пакеты VM UTM в этот список не входили. В 0.5 добавлены независимые места поиска, их статусы и сохранение частичного результата.

Для UTM проверяются стандартный контейнер, текущие Registry/Package и старые VMList/bookmarks, индекс Spotlight и выбранные пользователем папки. Config.plist проверяется до предложения переноса. Диски внутри VM учитываются в целом пакете, не предлагаются как отдельные куски. Конфигурации без локальной копии iCloud не загружаются. Пакеты по имени без доступа показываются отдельно и не могут быть выбраны для переноса до проверки.

Общие папки Mac, внешние ISO и ExternalDrives из реестра не объявляются собственностью UTM. Group Containers берутся из code-signing entitlements; наличие другого установленного владельца блокирует перенос. Корневая служебная метаинформация macOS, ссылки и специальные объекты сохраняются. Дочерние объекты общего контейнера проверяются отдельно: сокет не скрывает остальные файлы.

## Проверки

- Debug suite: 46/46. Финальная release suite: 46/46, без предупреждений компилятора.
- VM в sandbox: найден целый пакет, помечен как личные данные, перенесён и восстановлен в созданной тестами временной домашней папке. Содержимое синтетического диска совпало.
- Перемещённая VM: ссылка Registry найдена; VM перенесена перед её реестром и приложением; все объекты восстановлены.
- Поддержка современного Registry, старых словарей VMList, bookmark-массивов и относительных имён. Общие папки, подключённые образы и переход `../` не попали в кандидаты.
- Изменение реестра после просмотра и признак работающего UTM/QEMU блокируют перенос.
- Проверены HTTPStorages, WebKit, Application Scripts, Cookies, UUID-квалифицированный ByHost, короткое известное имя UTM и контейнер расширения приложения.
- Группы: тесты создали два собственных ad hoc подписанных приложения на основе копии `/usr/bin/true`, не запускали их. Entitlements прочитаны через Security. Общая группа защищена при появлении второго владельца; повторная проверка выполняется и при переносе.
- Специальный объект: собственный FIFO остался на месте и не скрыл обычный файл группы.
- Недоступный контейнер, отсутствующая папка и ссылка Documents: ошибка доступа не означает пустую папку, ссылки не обходятся, отдельно найденное приложение сохраняется.
- Источник с частичным ответом и последующим зависанием: дочерний процесс прекращён по тайм-ауту, найденные элементы сохранены со статусом timedOut.

Все изменяемые VM, диски, приложения, FIFO и журналы в этих тестах созданы самими тестами и удалены вместе с уникальными временными каталогами. Настоящие VM и UTM пользователя не переносились и не удалялись.

## Нативный интерфейс

В финальной сборке выполнен только просмотр данных установленного UTM 4.7.5. В списке появились оба существующих пакета виртуальных машин как отдельные пункты с предупреждением о личных данных, а также данные его контейнера и общего контейнера.

Обе VM остались неотмеченными. По умолчанию отмечен только UTM.app; соответствующий итоговый размер — размер приложения. Перенос или подтверждение удаления для настоящего UTM не запускались. Разрешения macOS не расширялись. Список открыт для просмотра пользователем.

## Ограничения

Поиск не может гарантировать обнаружение произвольных документов любого приложения вне известных мест. Spotlight не видит неиндексируемые диски. Недоступные места обозначаются явно; для конкретных папок есть системный выбор. Служебные объекты, разделяемые данные и чужие файлы не добавляются к удалению автоматически. Размер VM логический и может превышать физически занятое место разреженного диска. После переноса место освободится только при очистке Корзины пользователем.

Официальный исходный код, по которому проверены форматы UTM: [UTMRegistry](https://github.com/utmapp/UTM/blob/1c5e2150696cf86dc6e451212a8ad4555b2b63b2/Services/UTMRegistry.swift), [UTMRegistryEntry](https://github.com/utmapp/UTM/blob/1c5e2150696cf86dc6e451212a8ad4555b2b63b2/Services/UTMRegistryEntry.swift), [UTMData](https://github.com/utmapp/UTM/blob/1c5e2150696cf86dc6e451212a8ad4555b2b63b2/Platform/UTMData.swift), [UTMConfiguration](https://github.com/utmapp/UTM/blob/1c5e2150696cf86dc6e451212a8ad4555b2b63b2/Configuration/UTMConfiguration.swift).
